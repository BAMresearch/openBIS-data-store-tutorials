How to Use This Tutorial

This tutorial introduces the basic functionalities of the openBIS Electronic Laboratory Notebook (ELN) through a series of guided exercises. It is designed for beginner users and demonstrates how research data, metadata, and experimental workflows can be represented in openBIS, the underlying software of the BAM Data Store.

The tutorial uses a simplified example project for material synthesis and characterization. All experimental descriptions, metadata, and datasets included in the tutorial are synthetic example data created exclusively for training and demonstration purposes.

Tutorial Structure

The tutorial is divided into two main sections:

  • Introduction: Provides an overview of the openBIS ELN, the core data model used in the Data Store, and the main concepts required to complete the exercises.
  • Exercises: Contains step-by-step exercices that guide users through common ELN funtions using the graphical user interface (GUI) of openBIS.

Structure of the Exercises Section

The Exercises section is organized into sequential tasks. Each exercise focuses on a specific ELN workflow, such as creating Projects and Collections, registering Experimental Steps, applying Templates, uploading datasets, editing metadata, deleting objects.

The exercises should be completed in the order provided, as later steps may depend on objects, collections, or datasets created in earlier exercises.

Each exercise typically includes:

  • Exercise title: Identifies the task to be completed.
  • Short description: Explains the purpose of the exercise.
  • Step-by-step instructions: Describes where to navigate, which menu options to select, and which values to enter.
  • Tutorial values: Provides example names, templates, or metadata values required to reproduce the tutorial example.
  • Notes and warnings: Highlights important information, limitations, or actions that cannot be undone.

Recommended Workflow

  1. Read the introduction before starting the exercises.
  2. Follow the exercises in the order provided.
  3. Use the predefined tutorial values where indicated.
  4. Check notes and warnings carefully before saving, deleting, or modifying entries.
  5. Verify that each Project, Collection, Object, or Dataset has been created correctly before continuing.

Important Note

The tutorial content has been reviewed for consistency and usability for the tutorial purposes. However, it has not been scientifically validated and should not be considered scientifically accurate, reproducible, or suitable for research use.
