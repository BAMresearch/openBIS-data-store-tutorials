Tutorial sequence

This tutorial introduces the Lab Notebook part of the synthetic “Material Synthesis” example. The Experimental Steps and datasets registered here will later be connected with Instrument, Chemical, and Sample objects registered in the Inventory.

Key concepts

Lab Notebook

In the Lab Notebook, each user has a personal workspace (Space in openBIS) for organizing research projects, experiments, simulations, analyses, and other activities that generate research data.

Research activities can be represented as Experimental Steps organized within Collections of a Project. Datasets should be attached to the Experimental Step that describes how the corresponding data was generated. Experimental Steps can also be connected with other Experimental Steps and related Inventory objects, such as instruments, chemicals, software, and samples, using parent-child relationships.

These connections make it possible to represent research workflows and document the provenance of research data in the Data Store.

Lab Notebook structure for "Material Synthesis"

The tutorial example "Material Synthesis" uses the Data Store hierarchy Space → Project → Collection → Object → Dataset. In the Lab Notebook, research activities are represented as Experimental Step objects and datasets are attached to the corresponding Experimental Steps.

In this tutorial, you will work within your User Space in the Lab Notebook. You will register a Project, Collections, and Experimental Steps, and attach datasets to the corresponding Experimental Steps. In follow-up tutorials, you will register the corresponding Inventory items and connect them with these Experimental Steps to represent the complete research workflow in the Data Store.

Data organization: openBIS 20.10.12 also supports folders and subfolders. However, the Data Store recommends primarily organizing research information using the core structure Project → Collection → Object → Dataset. Collections, metadata, and parent-child relationships provide a consistent and scalable way to organize and connect research information while keeping the Lab Notebook navigation concise.

Tutorial workflow

  1. Create the Project and Collections used to organize the “Material Synthesis” example.
  2. Register Experimental Steps manually and using predefined templates.
  3. Edit the prepared structure and register the remaining Experimental Steps.
  4. Upload research data as datasets and review the uploaded data.
  5. Filter registered Experimental Steps and create an Advanced Search query.

Step 1: Register a Project

Create a Project in the Lab Notebook to represent the research project Material Synthesis.

Instructions:
  1. Select the upper LAB NOTEBOOK tab.
  2. In the left-hand navigation menu, select Home Space.
  3. Click + Project.
  4. Enter Code: MATERIAL_SYNTHESIS.
  5. Enter the following Description: This tutorial project demonstrates a simplified workflow for the synthesis and characterization of a material within openBIS. The experimental descriptions, metadata, and datasets are synthetic example data created solely for training and demonstration purposes.
  6. Review all entries and click Save.

General information

Mandatory fields in openBIS are marked with an asterisk (*). Project codes should be meaningful and should follow the naming conventions agreed for the Data Store. Once saved, a project code cannot be modified or reused.

Identification information: If the Code or Description fields are not displayed, open the More drop-down menu and select Show Identification Info.

General information: Project access

Access in openBIS can be managed at the Space and Project levels. Permissions assigned to a Project are inherited by its Collections, Objects, and Datasets.

For collaborative work within or across divisions, use a dedicated Project and assign the appropriate Observer, User, or Admin role to the required users or groups. For more information, see roles and rights in the Data Store .

Step 2: Register Collections

Collections organize related Experimental Steps and other research activities within a Project. In this tutorial, you will create five Collections for the “Material Synthesis” workflow.

Instructions:
  1. Select the Material Synthesis Project.
  2. Click + Other.
  3. Select Collection.
  4. Leave the autogenerated Code (*) unchanged.
  5. Enter Synthesis as the Collection Name.
  6. Leave Default object type empty.
  7. Select List view as the Default Collection View.
  8. Review all entries and click Save.
Repeat the procedure to create the following additional Collections: Treatment non-destructive, Structure_TEM, Parameter 1, and Parameter 2.

Step 3: Register an Experimental Step

Research activities that generate data, such as experiments, measurements, simulations, or analyses, can be represented in openBIS as Experimental Steps.

Instructions:
  1. Navigate to the Synthesis Collection.
  2. Select More → New Object.
  3. Click Select an object type.
  4. Select Experimental Step.
  5. Leave the autogenerated Code unchanged.
  6. Enter Material Demo 001 as the Name.
  7. Complete all mandatory (*) and other relevant properties.
  8. Review all entries and click Save.

General information

  • The Code is mandatory and is normally generated automatically.
  • The Name should be meaningful and descriptive.
  • Only fields marked with an asterisk (*) are mandatory.
  • Experimental Steps can be edited after registration.

Step 4: Register an Experimental Step using a Template

Templates help standardize metadata and reduce repeated manual data entry when similar Experimental Steps are registered.

Instructions:
  1. Navigate to the Synthesis Collection.
  2. Select More → New Object.
  3. Select the Object Type Experimental Step.
  4. Open the Templates tab.
  5. Select the template Material Synthesis.
  6. Leave Merge current parents/children disabled.
  7. Click Accept.
  8. Leave the autogenerated Code unchanged.
  9. Enter Material Synthesis as the Name.
  10. Enter Start Date and End Date using the calendar selector.
  11. Enter a comment in the Comments section.
  12. Review all entries and click Save.
Templates: Templates must be created for a specific Object Type before they are available for selection. In the Data Store, template configuration is performed by users with Group Admin rights, typically Data Store Stewards.
Template behavior: A template can only be selected during object creation; it cannot be applied retrospectively to an existing object. If a template contains parent-child relationships that need to be combined with relationships already present, use Merge current parents/children.

Step 5: Edit Collections and Objects

Consistent naming helps maintain a clear overview of registered Projects, Collections, Objects, and Datasets. In this step, you will rename one Collection and delete one Experimental Step.

Exercise: Edit a Collection

Instructions:
  1. Select the Collection Structure_TEM.
  2. Select More → Edit Collection.
  3. Open the Edit tab.
  4. Change the Name to Parameter 2 Analysis.
  5. Review the entry and click Save.
  6. Refresh the page if the updated name is not displayed immediately.

Exercise: Delete an Experimental Step

Instructions:
  1. Navigate to the Synthesis Collection.
  2. Select Material Demo 001.
  3. Click the DELETE tab.
  4. Enter a value in the mandatory Reason (*) field.
  5. Leave Delete also all descendants unchecked.
  6. Click Accept and confirm the deletion.
  7. Return to the Collection and confirm that the object is no longer listed.
Deletion: Deleting descendants may also remove connected objects and attached datasets. If you only want to remove the selected object, leave the descendant-deletion option unchecked.

General information: Restore deleted objects

Deleted objects are moved to the Trashcan, where they can be restored or permanently deleted.

  • Select TOOLS → Trashcan.
  • Select a deleted object.
  • Open the Operations drop-down menu.

Step 8: Filter and Search

Collections can be filtered by displayed properties and property values. Advanced Search can be used to locate specific Objects or Datasets across openBIS.

General information: Filter a Collection

  • Select the relevant Collection.
  • Open the COLUMNS tab.
  • Select the properties to display.
  • Use the available column filters to restrict the displayed objects.

Exercise: Advanced Search

Instructions:
  1. Select TOOLS → Advanced Search.
  2. Select Search For: Dataset.
  3. Select the AND operator.
  4. Define the first criterion: Field Type: All, Field Value: synthetic.
  5. Add a second criterion: Field Type: Property, Field Name: Modification Date, comparator thatIsLaterThanOrEqualTo (Date), and select the tutorial date.
  6. Add a third criterion: Field Type: Property, Field Name: Registrator, comparator thatEqualsUserId, and select your user.
  7. Run the search.
  8. Save the query as Datasets-synthetic.

Reuse a saved search

Instructions:
  1. Select TOOLS → Advanced Search.
  2. Select Datasets-synthetic from the saved-query list.
  3. Run the search to display the results.
