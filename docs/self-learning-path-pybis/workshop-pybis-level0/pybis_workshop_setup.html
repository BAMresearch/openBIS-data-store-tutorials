Install pyBIS and set up your workshop environment

A step-by-step guide for researchers with no prior experience using Python or command-line tools such as Miniforge Prompt, or Jupyter Notebooks.

Duration: 20–30 min.

This guide helps you prepare your computer to work with pyBIS for the first time. It includes a pybis environment required for the workshop. You do not need previous programming experience.

What tools will you use?

  • Python: the programming language used in the workshop.
  • pyBIS: a Python package for communicating with openBIS.
  • Miniforge3: a minimal installer for conda, which is used here to create and manage the isolated Python environment and install workshop packages.
  • Visual Studio Code (VS Code): an application for writing and running code.
  • Jupyter Notebook: an interactive document where you can write and run Python code one cell at a time.
  • Python environment: a separate workspace containing a Python version and the packages needed for the workshop.

Step 1: Install Visual Studio Code

1.1 Install VS Code

  1. Open the Symantec Software Portal.
  2. Search for Visual Studio Code and install it.
  3. Open VS Code from the Windows Start menu.

1.2 Install the Python and Jupyter extensions

  1. In VS Code, click the Extensions icon (four squares) in the left sidebar.
  2. Search for Python, select the extension published by Microsoft, and click Install.
  1. Search for Jupyter, select the extension published by Microsoft, and click Install.

If you see Installed or Uninstall, the extension is already installed.

Checkpoint: VS Code is installed with the Python and Jupyter extensions.

Step 2: Create pybis environment and install pyBIS package

A Python environment keeps the workshop packages together and separate from other Python projects.

What is a Python environment? A Python environment is a separate workspace containinga specific Python version and the packages needed for a project, such as pyBIS and Jupyter.

Why is creating an environment good practice? It keeps the workshop's packages separate from those used in other projects. This helps prevent conflicts between package versions, makes troubleshooting easier and allows you to work on different projects without affecting each other's setup.

For this workshop, a dedicated environment named pybis helps everyone work with a consistent Python setup while keeping their existing Python installations and projects unaffected.

After the workshop: You can continue using this environment to work with pyBIS and manage your own research data in openBIS. You do not need to create a new environment every time you use pyBIS. Simply activate and reuse it.

What if the environment stops working? Python environments can usually be repaired or recreated. Before creating a new one, try these troubleshooting steps:

  1. Check that you have activated the correct Python environment.
  2. Check that VS Code or Jupyter is using the correct Python kernel.
  3. Check that pyBIS and the required packages are installed in that environment.
  4. If necessary, reinstall missing packages or recreate the environment by following the setup instructions.

Remember: Recreating your Python environment does not affect research data stored in openBIS. Your notebooks and local research files will also remain safe as long as they are saved outside the environment folder.

2.1 Install Miniforge3

  1. Open the Symantec Software Portal.
  2. Search for Miniforge.
  3. Install Miniforge3 and wait until installation is complete.

2.2 Open Miniforge Prompt

  1. Click the Windows Start button.
  2. Search for Miniforge Prompt and open it.
How to use Miniforge Prompt?

Miniforge Prompt is a s a window where you type commands to tell your computer what to do. You will use it to create a Python environment and install packages.

For each command below, copy the text from the code box, paste it into the Miniforge Prompt (usually using Ctrl + V or right-click), and press Enter. Wait until the command finishes before continuing.

2.3 Create the pybis environment

  1. Copy the command below, paste it into the Miniforge Prompt, and press Enter:
    2. conda create --name pybis --channel conda-forge python=3.14
This creates an environment named pybis with Python 3.14. conda-forge is the package repository to obtain the software.

If the Miniforge Prompt asks Proceed ([y]/n)?, type y and press Enter.

2.4 Activate the environment

  1. Copy the command below, paste it into the Miniforge Prompt, and press Enter:
conda activate pybis

You should see (pybis) at the beginning of the command line, for example (pybis) C:\Users\yourusername>. This indicates that the environment is activate in Miniforge Prompt.

2.5 Install pyBIS and prepare the environment for Jupyter Notebooks

  1. Copy the command below, paste it into the Miniforge Prompt, and press Enter.
conda install --channel conda-forge pybis ipykernel

The pyBIS package lets Python communicate with openBIS. The ipykernel allows Jupyter Notebooks to run Python code using this environment.

Checkpoint: The pybis environment is ready. Close Miniforge Prompt and continue to Step 3.

Step 3: Open a Jupyter Notebook and select the pybis environment

3.1 Open a Jupyter Notebook in VS Code

  1. Open Visual Studio Code (VS Code).
  2. Choose File → New File.
  3. Select Jupyter Notebook.
What is a Jupyter Notebook? A Jupyter Notebook lets you write and run Python code in separate sections called code cells. To run a cell, click its ▶ Run button or press Shift + Enter.

3.2 Select the pybis environment

Before running Python code, choose which Python environment the notebook will use. In a Jupyter Notebook, this is means selecting a kernel (the Python interpreter that runs your code).

  1. Click Select Kernel in the upper-right corner of the notebook.
  1. Choose Python Environments.
  1. Select the pybis environment you created in Step 2.
Checkpoint: The notebook is configured to use the pybis environment. You should see pybis in the upper-right corner.

Step 4: Test your pyBIS installation

4.1 Run your first Python code

  1. Copy the code below and paste it into a notebook code cell.
  1. Press Shift + Enter to run the code.
print("Hello! My Python environment is working.")

You should see:

Hello! My Python environment is working.

This confirms that the notebook can run Python code.

4.2 Check that pyBIS is installed

  1. Move your mouse below the code cell you just ran.
  1. Click + Code to add a new code cell.
  1. Copy the code below, paste it into the new cell and press Shift + Enter.
import pybis

print("pyBIS was imported successfully!")

You should see the following output:

pyBIS was imported successfully!
What does import mean? In Python, import makes a package available for use in your code. If the cell runs without errors, pyBIS can be imported from the selected environment. You do not need to connect to an openBIS server for this test.

4.3 Save the notebook

  1. Press Ctrl + Shift + S.
  1. Choose a folder you can find again and save the notebook as pybis_installation_test.ipynb.

The .ipynb extension identifies a Jupyter Notebook file.

Checkpoint: Your notebook runs Python code, pyBIS can be imported, and your notebook is saved. You are ready to start working with pyBIS.

Troubleshooting: Common issues

Start with the five checks below. Use Miniforge Prompt for terminal commands, as in Step 2. The workshop environment is named pybis, uses Python 3.14, and installs pybis and ipykernel from conda-forge.

First identify the problem: If Python cannot import pybis, or VS Code cannot start the notebook kernel, this is an installation/environment problem. If pyBIS imports successfully but you cannot log in to openBIS, this is a connection or authentication problem. The installation test in Step 4 does not connect to a server.

Self-help check 1 — Open Miniforge Prompt and find your environment

Open Miniforge Prompt from the Windows Start menu. If it is missing, confirm that Miniforge3 was installed through the Symantec Software Portal (Step 2.1). If conda is not recognised, use Miniforge Prompt rather than a terminal that has not been configured for Conda.

conda env list

Look for an environment named pybis. If you see EnvironmentNameNotFound when activating, check the name shown in this list. If pybis is absent, follow Step 2 to create it.

Self-help check 2 — Activate pybis and verify Python

conda activate pybis
python --version
python -c "import sys; print(sys.executable)"

The prompt should begin with (pybis); Python should report 3.14 (or its patch version), and the displayed executable path should refer to the pybis environment. If not, return to Step 2.4 and activate the correct environment.

Self-help check 3 — Select the correct VS Code / Jupyter kernel

In your notebook, click Select Kernel → Python Environments → pybis, as shown in Step 3. Run this in a notebook code cell:

import sys
print(sys.executable)

The path should point to the pybis environment. If the kernel is missing, confirm that the Microsoft Python and Jupyter extensions are installed, then continue to check 4.

Self-help check 4 — Verify the required packages

In Miniforge Prompt, with (pybis) activated, run:

conda list pybis
conda list ipykernel
python -c "import pybis; print('pyBIS import successful')"

If ModuleNotFoundError: No module named 'pybis' appears, first check the notebook kernel (check 3). If pyBIS or ipykernel is missing from the environment, install the packages using the same command as Step 2.5:

conda install --channel conda-forge pybis ipykernel

If the notebook cannot start because ipykernel is missing, the same command installs it. Restart the kernel after installation.

Self-help check 5 — Check installation errors and test again

If Conda reports a network, SSL or permission error, check your organisation's network/VPN connection and retry the command from Step 2.5. Do not disable certificate verification or use administrator privileges as a workaround; ask IT support if the error persists.

Return to Step 4 and run the two notebook tests: print("Hello! My Python environment is working.") and import pybis. If both work, your local installation is ready.

Quick retry 6 — Restart VS Code and the notebook kernel

After installing packages or changing kernels, restart the notebook kernel. If necessary, close and reopen VS Code, reopen the notebook, select pybis again and repeat the Step 4 tests.

Last resort 7 — Recreate the environment

Last resort: Only remove the environment after completing checks 1–6. Keep notebooks and local research files outside the Conda environment folder. Removing an environment deletes the packages installed inside it. If you added other packages, note them before proceeding.

In Miniforge Prompt, deactivate the environment and remove only the environment named pybis:

conda deactivate
conda env remove --name pybis

Then recreate it with the exact workshop commands from Step 2:

conda create --name pybis --channel conda-forge python=3.14
conda activate pybis
conda install --channel conda-forge pybis ipykernel

Confirm any Proceed ([y]/n)? prompt as described in Step 2. Reopen VS Code, select the new pybis kernel and repeat the Step 4 tests.

Your data: Recreating this environment does not delete research data stored in openBIS. Local notebooks and files saved outside the environment folder are not removed by these commands.

Connection problems — pyBIS imports, but openBIS cannot be reached

Example: import pybis succeeds, but a later notebook cell cannot connect or log in to your openBIS server. This is different from a missing-package or kernel problem; do not recreate the Python environment just because a login fails.

  1. Check that the openBIS server address in the workshop notebook is correct.
  2. Check your network/VPN connection and whether you can access the openBIS web interface in your browser.
  3. Check your credentials or authentication method without sharing passwords or tokens in screenshots or Teams messages.
  4. If the web interface also fails, or access is denied, contact the Data Store team or IT support with the error message (redact sensitive details).

Updating packages after the workshop

If you have not used the environment for a while, you may want to update its installed packages. Updates can change package versions, so do not update as your first troubleshooting step immediately before the workshop. Open Miniforge Prompt and run:

conda update -n pybis --all -c conda-forge

After updating, select the pybis kernel and repeat the Step 4 tests. If you still need help, share a screenshot of the error in the workshop Microsoft Teams channel, without including credentials or tokens.
