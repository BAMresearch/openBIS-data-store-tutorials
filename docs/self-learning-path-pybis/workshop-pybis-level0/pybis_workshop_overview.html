Beyond the GUI: Hands-On with pyBIS and Data Modelling for Research Workflows

Five-hour user-friendly workshop combining Python-based research data management and collaborative research workflow modelling.

1. Workshop description

Discover how to manage your research data more efficiently in openBIS using Python, and learn how to represent your research workflows in openBIS-Data Store.

This five-hour workshop combines hands-on pyBIS (3.5 hours) with a separate conceptual data modelling session (1.5 hours). The data modelling activity does not require pyBIS.

Part 1 — Get hands-on with pyBIS

Using a guided Jupyter Notebook, you will connect to openBIS, retrieve your data, upload data, explore and filter objects, modify metadata and export results. You will also see how Python can simplify repetitive data management operations that would otherwise require several GUI interactions.

Two starting paths: If you completed the GUI Lab Notebook tutorial, you can reuse your existing objects. If not, guided setup cells help you prepare the minimum training objects required for the exercises.

Part 2 — Explore data modelling for research workflows

Learn how research activities, samples, results and their relationships can be represented in openBIS to support documentation and traceability. In small groups, develop a first draft of a workflow proposed by a participant. Identify which object types might be reused from the BAM Masterdata and which may need to be proposed to the Data Store team.

Who can join? Researchers interested in managing research data with openBIS. No prior Python experience is required. Bring a research workflow you could explain briefly to colleagues.

What you will learn

  • Run Python cells in a Jupyter Notebook and retrieve existing openBIS objects.
  • Explore, filter, update import data and export a list of objects with pyBIS.
  • Recognise opportunities to simplify repetitive data management tasks.
  • Describe a research workflow in terms of traceable steps, inputs, outputs and relationships.
  • Distinguish reusable BAM object types from potential new object-type proposals.
  • Understand the institutional workflow for proposing object types to the Data Store team.

Before the workshop

Follow the computer setup instructions and use the workshop Microsoft Teams channel for questions and troubleshooting. For the modelling activity, think of one real research workflow you would like to make easier to document and trace.
