Step 1: Download the Workshop Materials

Download the complete workshop package before starting the exercises. It contains the Jupyter Notebook, the Python helper.py file, and all required datasets.

Download workshop Materials ZIP file

  1. Click Download workshop ZIP file above to download the workshop materials.
  2. Open Windows File Explorer and locate the downloaded ZIP file (usually in your Downloads folder).
  3. Right-click the ZIP file and select Extract All…. Follow the prompts to extract the files.
  4. Open the extracted folder and check that it contains pybis_workshop_exercises.ipynb, helper.py, and the datasets folder.
  5. Keep the notebook and datasets folder in their original folder structure. Do not move individual files out of the extracted folder.
Checkpoint: You can see the exercise notebook and datasets in the extracted workshop folder.

Step 2: Open the exercise notebook in VS Code

  1. Open Visual Studio Code (VS Code).
  2. Choose File → Open Folder… and select the extracted workshop folder.
  3. Click the Explorer icon at the top of the left sidebar in VS Code, then click Open Folder. Navigate to the folder containing pybis_workshop_exercises.ipynb and click Select Folder at the bottom of the window.
  4. If VS Code asks whether you trust the folder, confirm only if it is the workshop folder supplied by the organisers.
  5. Click pybis_workshop_exercises.ipynb to open the notebook.
Checkpoint: The provided notebook is open in VS Code. You should see its introduction and the heading Step 0 - Check your workshop environment further down.
Back to top

Step 3: Select the pybis kernel

  1. At the upper-right of the open notebook, click Select Kernel (or the current kernel name).
  2. Choose Python Environments, if this option appears.
  3. Select the environment named pybis. It may also show its Python version and a path ending in envs/pybis/python.exe.
Why this matters: The notebook kernel determines which Python environment runs the exercise code. You do not need to activate pybis separately in Miniforge Prompt if VS Code already uses the correct kernel.
Checkpoint: The notebook's upper-right corner shows the pybis environment.
Back to top

Step 4: Run Step 0 in the notebook

  1. Scroll to Step 0 - Check your workshop environment.
  2. Run the first environment-check code cell using its ▶ Run button or Shift + Enter.
  3. Check the output. Look for Environment check passed.
  4. Run the next Step 0 cell, which displays the Python executable and checks the pybis and ipykernel packages.
  5. Read the remaining Step 0 instructions. Follow any additional preparation directions in the final workshop notebook as directed by the instructor.
Important: Run the notebook cells in order. Do not use Run All at this stage: later cells connect to the BAM Data Store and begin the exercises.
Checkpoint: The environment check passes, and the package check reports pyBIS and ipykernel without errors.

If something does not work

I cannot find the downloaded ZIP file

Check your browser's downloads list or the Downloads folder in Windows File Explorer. If the download did not complete, return to Step 1 and try again.

I cannot see the pybis kernel

Check that the Microsoft Python and Jupyter extensions are installed in VS Code. Close and reopen VS Code, then try Select Kernel → Python Environments again.

Step 0 reports the wrong environment

Return to Step 3 and select pybis. If necessary, open Miniforge Prompt and check the environment:

conda env list
conda activate pybis

You should see (pybis) at the beginning of the Miniforge Prompt command line. This terminal activation is for troubleshooting; you must still select the kernel in VS Code.

I see a Conda update warning

A message such as WARNING: A newer version of conda exists is normally informational, not a reason to stop the workshop. Do not update Conda during the session unless the instructor asks you to.

The notebook reports a missing package or helper.py

First check the selected kernel and that you opened the extracted workshop folder. Follow any download or installation instructions included in the final notebook. If helper.py is still missing, ask the instructor rather than changing the workshop files yourself.

The notebook runs, but connection to openBIS fails

This is a connection or access problem, not necessarily a Python installation problem. The instructor will guide the Playground connection in Part A. Check the server address, login method and permissions at that point.

Need help? Show the instructor the error message (or a screenshot). Avoid sharing passwords or access tokens in screenshots.

For installation problems, consult the computer setup guide.
