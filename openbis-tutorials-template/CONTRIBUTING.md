# Contributing Guidelines

## Branch Naming

Use descriptive branch names:

```text
feature/tutorial-inventory-basics
fix/eln-screenshot-paths
review/customization-template-update
```

## Pull Requests

Each pull request should include:

- Tutorial topic
- Target audience
- Learning objectives
- Screenshots or sample data used
- Reviewer notes

## Review Roles

Recommended review roles:

- Content reviewer: checks clarity, pedagogy, and completeness
- Technical reviewer: checks openBIS accuracy and reproducibility
- Editorial reviewer: checks language, structure, and consistency

## Commit Style

Use concise commit messages:

```text
Add inventory basics tutorial
Update ELN screenshots
Fix parent-child connection wording
```
