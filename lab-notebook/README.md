# ELN Tutorial

Welcome to the **ELN (Electronic Lab Notebook) Tutorial**.

This tutorial provides a self-guided learning path to help you understand and use the ELN effectively, with a focus on working with the data store.

## Self-Learning Path

The tutorial materials are available in:

`data_store_self_learning_path`

## Getting Started

1. Navigate to the `data_store_self_learning_path` directory.
2. Follow the tutorial materials in the provided order.
3. Work through the examples and exercises.
4. Experiment with the workflows to reinforce your understanding.

## Learning Objectives

By completing this tutorial, you should be able to:

- Understand the basic ELN workflow.
- Navigate and use the ELN data store.
- Follow common data-management workflows.
- Apply the examples to your own ELN use cases.
- Continue exploring the ELN independently.

## Recommended Approach

Work through the materials sequentially and reproduce the examples yourself.

Try making small modifications to the examples to better understand both **how** the ELN workflows work and **why** they are structured this way.
