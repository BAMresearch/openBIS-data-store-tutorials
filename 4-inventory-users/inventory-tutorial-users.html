Register samples in the openBIS Data Store

This tutorial shows division members who have been assigned the User role in the Data Store how to register inventory objects used in the synthetic “Material Synthesis” example. You will review inventory structures prepared by Data Store Stewards, register one Sample object manually, and batch-register additional Samples in the FB Inventory.

What you will learn

  • Locate inventory projects, collections, and objects prepared by Data Store Stewards.
  • Distinguish resources in the BAM Inventory from division-specific resources in the FB Inventory.
  • Register one Sample and identify yourself as the co-responsible person.
  • Batch-register Sample objects using an Excel file.
  • Distinguish an Excel file for batch registration from one used for batch update.

Before you begin

This tutorial is designed for openBIS version 20.10.12 and assumes that the inventory structure has already been prepared by a Data Store Steward. You must have the User role for the relevant FB Inventory projects.

  • Confirm that you can log in to the Data Store instance.
  • Confirm that the projects CHEMICALS_SYNTHESIS and SAMPLES_SYNTHESIS are visible in your division’s FB Materials space.
  • Confirm that the Instruments, Chemicals, and Samples collections are available.
  • If a required project or collection is missing, contact your Data Store Steward.

Tutorial workflow

  1. Review the objects registered by Data Store Stewards in the BAM and FB Inventories.
  2. Register one Sample in the SAMPLES_SYNTHESIS project and enter your username as the co-responsible person.
  3. Modify the supplied Excel file and batch-register additional Samples in the SAMPLES_SYNTHESIS project.

Step 1: Review the prepared inventory structure

Before registering Samples, review the inventory locations prepared by Data Store Stewards for the “Material Synthesis” example. Replace X.1 with your division identifier.

Inventory Space Project Collection Object type Purpose
BAM Inventory BAM Equipment X.1 Equipment Open Instruments Instrument Shared instruments used in the tutorial workflow
FB Inventory X.1 Materials CHEMICALS_SYNTHESIS Chemicals Chemical Chemicals used during material synthesis and treatment
FB Inventory X.1 Materials SAMPLES_SYNTHESIS Samples Sample Samples generated during the tutorial workflow
Instructions:
  1. Select the upper Inventory tab.
  2. In the left-hand navigation menu, open BAM Inventory and navigate to BAM Equipment → X.1 Equipment Open → Instruments.
  3. Review the Instrument objects registered for the tutorial.
  4. Open FB Inventory and navigate to X.1 Materials → CHEMICALS_SYNTHESIS → Chemicals.
  5. Review the registered Chemical objects.
  6. Navigate to X.1 Materials → SAMPLES_SYNTHESIS → Samples.
  7. Confirm that you can open the Samples collection and that the option for registering Sample objects is available.
Access note: All BAM members can view objects in BAM Inventory spaces. Members of a division can edit content in their corresponding division-specific BAM Inventory project. In the FB Inventory, you can edit content only where the appropriate User role has been assigned.

Step 2: Register one Sample

Register one Sample manually in the SAMPLES_SYNTHESIS project. Enter your Data Store username in the Co-responsible person property so that other users can distinguish who registered or shares responsibility for the Sample.

Instructions:
  1. Navigate to FB Inventory → X.1 Materials → SAMPLES_SYNTHESIS → Samples.
  2. Click + Sample. If the collection has a predefined object type, the button may appear as + Sample followed by the configured type.
  3. Enter a Sample name that follows the naming convention agreed within your division.
  4. Complete the required Sample properties.
  5. In the Co-responsible person field, enter your Data Store username.
  6. Review the information and click Save.
  7. Return to the Samples collection and confirm that the new Sample is displayed.
Naming convention: Establish and document a consistent naming convention for Samples within your division and, where relevant, with collaborating divisions. Because several users may register Samples in the same collection, names must allow each Sample to be distinguished unambiguously. This tutorial uses the Co-responsible person property for additional context. Other properties, such as Alternative name or Sample number, may also be used, but their format and use must remain consistent.

Step 3: Batch-register Samples

Use the supplied Excel file to register multiple Sample objects in one operation. Before uploading it, add your Data Store username to the Co-responsible person column for every Sample you are registering. Batch registration creates new objects; it does not update objects that already exist.

Download samples.xlsx

Instructions:
  1. Download samples.xlsx using the link above.
  2. Open the file and review the Sample records prepared for the “Material Synthesis” example.
  3. In the Co-responsible person property column, enter your Data Store username for every Sample you will register.
  4. Check that all Sample names follow the naming convention agreed within your division and with any collaborating divisions.
  5. Do not change the column headings, object type information, or worksheet structure.
  6. Save the modified Excel file under a clear filename, for example samples_X.1_your-username.xlsx.
  7. In openBIS, navigate to FB Inventory → X.1 Materials → SAMPLES_SYNTHESIS → Samples.
  8. Open the More drop-down menu and select XLS Batch Register Objects.
  9. In the Register Objects window, click Choose file. Depending on your browser language, the button may appear as Datei auswählen.
  10. Select the modified Excel file and verify that the correct filename is displayed.
  11. Click Accept to register the Sample objects.
  12. Return to the Samples collection and confirm that the new objects are displayed.
Important: Use batch registration only to create new objects. If an object from the Excel file already exists, stop and use the batch-update procedure described in the general information section.

General information: Prepare Excel files for batch registration and batch update

Batch registration and batch update are different operations and require differently prepared Excel files.

Operation Purpose How to obtain the Excel file Important checks
Batch registration Create new Sample objects Download the registration file provided in this tutorial or obtain a new batch-registration template from the relevant openBIS function. Use unique Sample names, enter your username under Co-responsible person, and preserve the headings and worksheet structure.
Batch update Modify Sample objects that already exist Navigate to the Samples collection and use the batch-update or export function to download a file containing the existing objects and their identifiers. Keep an unchanged backup, edit only the required property values, and never alter object identifiers or codes.

Preparing a file for batch registration

  1. Download the tutorial file or the appropriate batch-registration template.
  2. Add one row for each new Sample.
  3. Use the agreed Sample naming convention.
  4. Enter the responsible username in the Co-responsible person column.
  5. Do not change the column headings or worksheet structure.

Preparing a file for batch update

  1. Navigate to FB Inventory → X.1 Materials → SAMPLES_SYNTHESIS → Samples.
  2. Use the collection’s batch-update or export function to download an Excel file containing the existing Samples.
  3. Save an unchanged backup copy of the downloaded file.
  4. Edit only the property values that need to be updated.
  5. Do not change object identifiers, codes, column headings, or the worksheet structure.
  6. Verify that every row refers to the intended Sample before uploading the update file.
Note: Never use a batch-registration file to update existing objects. The exact names of the export and batch-update commands may depend on the configured openBIS interface. If the required commands are not displayed, contact your Data Store Steward before changing any existing objects.

Result

After completing this tutorial, you should be able to locate the inventory objects prepared for the “Material Synthesis” example, register one Sample manually, identify yourself as the co-responsible person, batch-register Sample objects in the SAMPLES_SYNTHESIS project, and distinguish batch registration from batch update.
